# AWS Technical Update: Controlling and Monetizing Traffic from AI Bots with AWS WAF

The rapid development of artificial intelligence models and AI Agents has led to a significant increase in automated traffic (bots) designed to scrape data across websites and API systems. To help content providers manage their resources effectively, AWS WAF has added a new feature to its Bot Control solution, enabling the control and pricing of traffic from AI Bots.

### Key highlights of this new feature:

* **Setting access pricing**: Allows administrators to set prices for data scraping or API calls made by AI Bots and automated harvesting systems.
* **Payment gateway integration**: Supports monetization via third-party payment partners and automatically grants access credentials once the transaction is completed.
* **Edge-level enforcement**: Permission checks and traffic control are handled directly at the edge infrastructure, reducing the load on the origin servers.

This update equips publishers and enterprises with the necessary tools to proactively manage data sharing with AI models while optimizing infrastructure operating costs.
