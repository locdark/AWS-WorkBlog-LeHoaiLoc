### Week 3 Objectives:
* Study CI/CD models on AWS to automate the application integration and deployment process using AWS CodePipeline, GitHub, and Amazon S3.
* Explore and practice with Amazon CloudWatch, AWS Lambda, and Amazon Cognito, and study how to combine Lambda, Amazon S3, and Amazon DynamoDB for serverless applications.
* Start building the codebase structure for the FoodieRecipe project, including the Admin dashboard layout in Next.js and the module structures in the NestJS backend connected to the RDS database.
* Implement authentication and security (Authentication/Authorization) mechanisms for the Admin portal using JWT and NestJS Guards connected with the Client login interface.
* Update worklogs and sync all project source codes to GitHub.
