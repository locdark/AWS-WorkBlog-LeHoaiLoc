### Week 1 Objectives:
* Get acquainted with the working environment at First Cloud Journey (FCJ), understand the workflow, and collaborate with team members.
* Equip foundational knowledge of AWS Cloud computing, common service groups, and resource management methods on the AWS platform.
* Practice using AWS accounts by configuring security with MFA, setting up AWS Budgets, and deploying basic services in the Free Tier environment.
* Study authorization mechanisms with IAM, build network infrastructure using Amazon VPC, and deploy EC2 instances for study and application development.
* Align on ideas and development direction for the FoodieRecipe project, and explore Next.js, NestJS technologies combined with AWS services to build the system.
* Explore and set up the initial basic development environment for the project.

* Quickly integrated into the internship environment and grasped the workflow of the First Cloud Journey team.
* Understood foundational AWS Cloud concepts, including infrastructure architecture, service groups, and resource management methods.
* Completed AWS account registration, enabled Multi-Factor Authentication (MFA), set up AWS Budgets, and completed basic hands-on program labs.

* Agreed on the FoodieRecipe project topic, analyzed initial requirements, set up the starter code repository for Next.js and NestJS, and pushed to GitHub for version control.
* Established a foundation in AWS cost management, learned how to use AWS Free Tier effectively, and built a plan to continue researching and applying AWS services.
